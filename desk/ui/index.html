Paja Desk

Paja Desk is running . What should happen to those runs?

Each run finishes the step it is on. One that hasn't stopped after a few seconds is ended, with its agents and checks. Paja Desk closes once they have all ended.

Repositories

Runs start the installed paja run in the repository's checkout, exactly as in a terminal. Paja checks the repository first with paja doctor and won't start while a check fails.
