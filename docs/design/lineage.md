# Lineage

Paja is written from scratch, but its ideas come from public projects. This page credits them.

| Idea in Paja | Where it comes from |
| --- | --- |
| Harness engineering: domain harness, canon, workflow and workspace as separate layers | Paul Gross's [harness engineering writing](https://grosscode.net/) |
| Ahjo's isolated feature environments with their own ports and services | Paul Gross's [Winter](https://github.com/paul-gross/winter) |
| Jono's queue and leases, Mestari's workflow graphs with fix loops, the mission-control board behind Paja Desk | Paul Gross's [Blizzard](https://github.com/paul-gross/blizzard) |
| Mestari's build modes and cold reviews | Paul Gross's [winter-workflow](https://github.com/paul-gross/winter-workflow) |
| A person approves the spec, agents do the rest; an inbox of asks; a secrets broker | [Legion](https://github.com/sjawhar/legion) |
| Post-merge verification with automatic revert; a periodic "does it actually run" audit; an escalation ladder | [Dark Factory](https://github.com/leodearden/dark-factory) |
| Escalating rarely, in batches, with options and a recommendation; layered containment | [Remudero](https://github.com/craigoley/remudero) |
| Spec-first work with gap and drift detection; deterministic next-task ranking | [livespec](https://github.com/thewoolleyman/livespec-orchestrator-beads-fabro) |
| One inbox for every agent's questions | [Coral](https://github.com/cdknorow/coral) |
| A harness-agnostic, minimal core | [Scion](https://github.com/GoogleCloudPlatform/scion) |
| Measuring factories by unattended output | Paul Gross's [amazing-software-factories](https://github.com/paul-gross/amazing-software-factories) |
